# Note naming conventions <!-- Metadata: type: Note; tags: documentation; created: 2024-07-04 12:46:30; reads: 136; read: 2026-09-20 17:16:01; revision: 17; modified: 2026-09-20 17:16:01; -->
Overview of conventions which will make navigation through the data faster.


## ABBREV: phrase | phrase.cz <!-- Metadata: type: Note; tags: synonym; created: 2026-09-12 09:19:55; reads: 53; read: 2026-09-20 17:16:01; revision: 10; modified: 2026-09-20 17:08:55; -->
Convention:

* **synonyms** for a phrase

Example:

* `Feature | Variable | Příznak`
* `ML: Machine Learning | Strojové učení`


## ABBREV: expanded abbreviation <!-- Metadata: type: Note; created: 2024-07-04 12:47:42; reads: 92; read: 2026-09-20 17:16:02; revision: 12; modified: 2026-09-20 17:11:28; -->
Convention:

* ABBREVIATION: Expanded abbreviation
* autolinking is aware of this convention in both `ABBREVATION` and `expanded abbreviation`
  are considered to be links

Example:

* `NLTK: Natural Language ToolKit`


## phrase >>> <!-- Metadata: type: Note; tags: link; created: 2024-09-04 08:18:38; reads: 84; read: 2026-09-20 17:16:02; revision: 11; modified: 2026-09-20 17:09:16; -->
Convention:

* `phrase >>>` is [Link](...) to the actual content
  i.e. another Note or Notebook

---

This is convention for link which can be easily distinguished
in search and list.

Example:

* `Docker >>>` is name of the Note which links to Docker where is actual content
* `Docker` is the name of the Note with content.
## [phrase] description <!-- Metadata: type: Note; created: 2024-07-04 12:46:45; reads: 110; read: 2026-09-20 17:16:15; revision: 20; modified: 2026-09-20 17:16:15; -->
Convention:

* Use it whenever you do **not** want to be prefix interpreted as abbreviation.
* Useful when finding Notebook/Note by name to faster find out
  the context in which is the term used.
* Hints:
    - It's like `[group] Subject` in newsgroup

Examples:

* `[Docker] Tips and tricks`

# Note emoji prefixes convention <!-- Metadata: type: Note; created: 2026-09-13 10:44:44; reads: 37; read: 2026-09-20 17:16:19; revision: 10; modified: 2026-09-20 17:14:41; -->
I use the following emojis as prefix of Note names:

* 🎯🚀🧪🌟🔧🐞📄🗑👁️

* goal: 🎯
* feature: 🚀
* enhancement: 🌟
* fix: 🔧
* bug: 🐞
* test: 🧪
